# Showcase-видео

Ролик собирается из настоящего рендера игры, без записи экрана: браузер без окна
останавливает игровой цикл, и время в нём идёт только по команде, по 1/60 с, два тика на кадр
видео (30 к/с). Поэтому кадры получаются ровными даже на программном WebGL, а все
события в сцене воспроизводимы: `Math.random` засеян, каждая сцена снимается на свежей странице.

Звук в браузере выключен. Вместо записи режиссёр (`capture/director.js`) логирует каждый
сэмпл, который игра запускает: файл, скорость, громкость, расстояние и угол до слушателя,
окклюзию, посыл в реверберацию, огибающие фоновых петель. `edit/sfxmix.py` раскладывает
те же файлы из `public/sfx` по этой разметке офлайн, поэтому звук совпадает с картинкой
до кадра. Музыка (`edit/mix.py`) собрана тоже только из сэмплов игры.

## Сборка

Нужны Node 18+, Playwright с Chromium, Python 3 с numpy и Pillow, ffmpeg.

```bash
npm run build && npm run preview -- --port 4173      # в отдельном терминале
node trailer/capture/final.cjs                       # кадры и звуковые логи в trailer/build/frames
PREVIEW=1 node trailer/capture/final.cjs             # быстрый прогон: каждый 15-й кадр, 1280×720
cd trailer/edit
python3 mix.py                                       # mix_no_vo.wav, и mix_full.wav, если есть vo/
python3 edit.py picture.mp4                          # картинка 1920×1080, 30 к/с
ffmpeg -i picture.mp4 -i mix_no_vo.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 320k echo_showcase_no_vo.mp4
```

Отдельную сцену можно перезаписать: `node trailer/capture/final.cjs reveal`.
`GAME_URL` задаёт адрес игры, `PLAYWRIGHT_MODULE` — путь к Playwright, `FRAMES_DIR` — куда класть кадры.

Монтаж целиком описан в `edit/timeline.py`: клипы (сцена, первый кадр, длительность,
грейдинг, наезд), карточки, переходы, подписи с клавишами и строки озвучки с таймкодами.
`edit.py` и `mix.py` читают один и тот же список, так что правка тайминга в одном месте
сдвигает и картинку, и звук, и окна приглушения под голос.

Сцены задаются в `capture/shots.js` (глава I) и `capture/shots2.js` (глава II): позиция и
взгляд игрока, нажатия клавиш по кадрам, появление и маршрут твари. Красные волны шагов
в игре видны только при вслушивании; в некоторых сценах режиссёр держит их видимыми
(`ctx.listen`), потому что в ролике не всегда можно стоять на месте с зажатой V.

Рендер на CPU (SwiftShader) стоит 4–6 секунд на кадр при 1920×1080 в качестве low,
весь ролик снимается за 3–3.5 часа. С GPU — в разы быстрее.

Текст озвучки и таймкоды — в [VOICEOVER.md](VOICEOVER.md).
