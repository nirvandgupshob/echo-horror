# ЭХО

Хоррор от первого лица в браузере. Ты слепой оператор-слухач на подземном объекте «Камертон», 1987 год. Видишь только то, что звучит: каждый шаг, стук трости и всплеск разворачивается волной по стенам. Что-то в темноте охотится на звук.

**Исходная опубликованная игра:** https://tg-prplx.github.io/echo-horror/
Версия с главой II запускается локально командами из раздела «Запуск локально».

Перед началом — экран с рекомендацией наушников и предупреждением о резких звуках и вспышках. В меню доступны настройки звука, мыши и графики, управление и титры. Текстуры и звуки загружаются с отдельным индикатором прогресса.

Игра сохраняет прогресс в контрольных точках. «Продолжить» возвращает к последней из них; новая игра запрашивает подтверждение перед заменой сохранения.

## Глава II — «Ниже тишины»

После закрытия лифта первая глава продолжается спуском на горизонт −11.
Кабина переносится из первой главы целиком: исходные меши, материалы,
створки, дверная рама, поручни, кнопка и рифлёный пол. При переходе сохраняется
положение игрока относительно кабины; отдельной новой модели лифта нет.
Кабина резко останавливается; удержание **E** раздвигает створки обеими руками.
Отпущенная створка остаётся на защёлке — продолжить можно с достигнутого положения.

Для отдельного запуска выберите **«Горизонт −11»** в главном меню.
Этот запуск начинает новое сохранение с движения лифта вниз.

Новый уровень — преимущественно пещеры, в которые вросли палаты и оборудование:
нижний больничный блок, затопленная перевязочная, «Зал подвесов» над провалом,
палата 0, соляное горло и нижняя штольня. У провала два обхода; есть низкий
тихий лаз; над провалом висят девять погибших шахтёров в касках и спецодежде,
на тросах с креплениями к своду. Вагонетки стоят на рельсах, трубопроводы
закреплены на опорах, дренажный насос подключён шлангом к затопленному полу.
Новый северный обход ведёт в геодезическую камеру; южный — через насосный
резервуар и резонансную галерею. Откройте дренаж, настройте резонатор,
найдите запасной ПН-2 на столе геодезиста, восстановите южный фидер и
согласуйте три частоты (II · 0 · I). Предохранитель можно установить в фидер
сразу после находки, независимо от порядка посещения остальных станций. Вслушивание рядом с галереей повторяет
сигнатуру звуком. После этого можно открыть затвор нижней штольни.

После настройки резонатора появляется паук: ползает по стенам и сводам,
его щелчки привлекают основного преследователя. Наведите фонарь на паука
и задержите луч, чтобы отогнать его. При задержке дыхания и вслушивании
фонарь автоматически выключается; **T** включает его снова.

Скальная оболочка непрерывная, с неровным грунтом, уклонами и уступами;
высота игрока, ног, трости и оборудования согласована с геометрией пола.
У ямы неровная кромка и скальные стенки в глубину. Новые текстуры породы,
грязи и земли взяты из ambientCG (CC0), источники указаны в CREDITS.md.
После дренажа на новом горизонте появляется преследователь.

Под шестью кроватями на полу можно спрятаться по **E** и выбраться повторным
нажатием. Камера опускается к полу; монстр ищет укрытия и слышит дыхание,
как в первой главе. **Q / ПКМ** — задержать дыхание.

У провала нет невидимых стен для игрока: шаг за край приводит к падению
и смерти. Повтор возвращает к последней контрольной точке. Преследователь
строит путь по обходам; край удерживает его также при рывке и принюхивании.

Оформление продолжает первую главу: те же модели коек и медицинских деталей,
грязная эмаль, ткань, трубопроводы, бумага, подтёки и плесень. Мебель сохраняет
материалы первой главы, а скалы и минералы
используют карты из `public/tex/cave/`. Баланс яркости пола, ткани и металла
совпадает с первой частью; пространство проявляется звуком. Таблички также
видны через эхо. Капли, искры и фон используют общий обработчик первой главы;
подсказки, цели и названия помещений выводятся её обычным интерфейсом.

Для скал и минералов используются **24 PBR-материала / 72 карты**, 512×512:
камень, сланец, натёки, кальцит, соль, глина, ил, водоросли, окисленный металл,
эмаль, ткань и новая керамика. Помещения собраны из общих больничных моделей и шахтного оборудования:
напольные стеллажи, насос с трубопроводами, приборный пульт, лебёдка,
вагонетки на непрерывных рельсах и вентиляция. Вход разделён на приёмную
и лечебный отсек, а выходной затвор встроен в настоящую перегородку. Текстуры воспроизводятся командой
`python tools/generate-cave-materials.py` (нужны numpy и Pillow).

Контрольные точки сохраняются после открытия лифта, дренажа и настройки
резонатора; «Продолжить» и повтор после смерти возвращают в нужную главу.
Пауза останавливает спуск, работу руками и все игровые таймеры.

Проверки: `node --test tests/*.test.js`; сборка: `npm run build`.
Браузерная проверка: запустить `npm run build` и `npm run preview -- --port 4173`,
затем `node tools/verify-cave.cjs` (Playwright и установленный Chrome;
`PLAYWRIGHT_MODULE` позволяет указать путь к Playwright).

## Управление

| | |
|---|---|
| WASD | идти |
| Shift | бежать (громко) |
| C | красться (тихо) |
| F | стук тростью — осмотреться |
| Q / ПКМ | задержать дыхание |
| ЛКМ | бросить камень |
| E | взаимодействие (некоторое — удерживать) |
| V | вслушаться: замереть и понять, откуда идёт звук |
| 1 / 2 / 3 | заслонки перехода / люка / служебной двери (в лифтовом холле) |
| 4 | сейсмодатчик |
| Подойти вплотную лицом к заслонке | автоматически подпирать рукой; у люка — присесть |
| Esc | пауза |

## Запуск локально

```bash
npm install
npm run dev
```

Сборка: `npm run build` (результат в `dist/`).

## Технологии

three.js, Web Audio API (HRTF, свёрточная реверберация), Vite. Освещение — собственный шейдер «эхо-волн» поверх трипланарных PBR-текстур.

Код распространяется по лицензии [MIT](LICENSE). Сторонние звуки и текстуры сохраняют свои лицензии CC0 / CC-BY 3.0; авторы и источники указаны в [CREDITS.md](CREDITS.md).

На телефоне игра работает в горизонтальном положении. Слева — аналоговый джойстик, по свободной части экрана можно осматриваться. «Действие», «Не дышать», «Слушать» и «Бег» работают при удержании; «Тихо» переключает приседание. У лифта появляются кнопки трёх заслонок и датчика. При повороте телефона вертикально игра ставится на паузу. Сенсорные кнопки проходят через тот же CRT, что и мир; зоны касания учитывают изгиб стекла.

Рендер отсеивает статические участки за постоянными стенами и вне камеры, сохраняя исходные треугольники, материалы и выбранные эффекты.

Рендер автоматически выбирает WebGPU при его доступности (HTTPS или localhost), иначе запускает WebGL 2. Движок можно выбрать в настройках. При потере WebGPU игра возвращается на WebGL без сброса игрового состояния. В режиме «Авто · цель 60 FPS» разрешение мира плавно меняется по нагрузке GPU в пределах 72–100%; текст и CRT рисуются в разрешении экрана. Исходные текстуры, рельеф, свечение и акустическое освещение сохраняются. «Полное разрешение» отключает регулировку. F3 показывает движок, FPS, время GPU/CPU и фактический размер мира.

Глава II начинается в нижнем больничном блоке: коридоры, плитка и знакомые предметы постепенно сменяются обнажённой породой. У выхода из лифта на полке лежит динамо-фонарь. **E** — взять, **T** — включить/выключить, удерживать **R** — трясти и заряжать. Полного заряда хватает примерно на 90 секунд света; шум зарядки слышит существо. На телефоне есть кнопки «Свет» и «Трясти». Фонарь и заряд сохраняются в контрольных точках. В обеих главах используются общие материалы, модели больничных предметов, вода, управление, руки и основной игровой цикл.

Во второй главе помещения различаются материалами и оборудованием: приёмная с терраццо,
перевязочная с линолеумом и голубой плиткой, дренажная с компрессором,
шахтные склады с кабельными барабанами и инструментом, лаборатория и соляной проход.
12 дополнительных наборов текстур (36 карт 512×512) созданы для проекта;
новое оборудование собирается в статические группы и использует общие материалы.
